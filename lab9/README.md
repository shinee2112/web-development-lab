# Lab 9 — JavaScript Validation

Лаб 9-ийн дагуу санал хүсэлтийн form validation болон JavaScript алгоритмын дасгалуудыг хэрэгжүүлэв.

## Хуудсууд
- `index.html` — Gallery, санал хүсэлтийн form, JS туршилтын тайлбар.
- `js/algorithms.js` — шаардсан 8 алгоритм.
- `js/validators.js` — шаардсан 4 validation функц.
- `js/main.js` — console туршилтууд болон form-той холбосон validation.

## Алгоритмын функцүүд
`sumTo`, `factorial`, `isPrime`, `fizzBuzz`, `countVowels`, `isPalindrome`, `maxOf`, `digitSum`.

## Validation дүрэм
- Нэр: trim; 2–50 тэмдэгт; цифргүй.
- Имэйл: хоосон биш; нэр@домэйн.өргөтгөл хэлбэр; whitespace-гүй.
- Нууц үг: 8-аас доошгүй тэмдэгт; зайгүй; үсэг ба тоотой.
- Зурвас: trim; 10–500 тэмдэгт.

Validation нь талбараас гарахад болон submit хийхэд ажиллана. Амжилттай submit болсны дараа demo мессеж харуулна; backend рүү мэдээлэл илгээхгүй.
